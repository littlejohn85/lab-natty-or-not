# Natural ou Fake Natty? Como Vencer na Era das IAs Generativas

Ebook Hipertrofia Muscular

## 📒 Descrição
"esse ebook fala a respeito da hipertrofia de uma forma mais técnica e resimida!

## 🤖 Tecnologias Utilizadas
chatgpt 3.5 para conteúdo textual e imagem 
canvas para montar o ebook

## 🧐 Processo de Criação
enviei um prompts ao chatgpt 3.5, pedindo outro prompts para criar o ebook completo de hipertrofia e criar uma imagem para usar de capa relevente ao assunto

## 🚀 Resultados
conteúdo veio bem completo de forma técnica e resumida com 8 paginas sendo capa, sumario, conteúdo, aviso legal e sobre autor.

## 💭 Reflexão (Opcional)
desafio foi bem fácil pois já venho algum tempo estudando e interagindo com varias AI generativas mais estou em busca de mais conhecimento.
